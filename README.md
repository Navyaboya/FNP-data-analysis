# FNP Sales Performance and Revenue Analytics Dashboard (Excel + MySQL)

> **Guided project:** built by following the WsCube Tech data analytics tutorial using the FNP (Ferns N Petals) dataset, then reproduced independently. The "My contribution" section lists the parts I did myself.

## Overview
Analysis of 1,000+ FNP e-commerce orders using Excel (Power Query, Pivot Tables) and MySQL, with an interactive dashboard for tracking revenue, orders and delivery performance.

## Business questions answered
1. Total revenue
2. Average order-to-delivery time
3. Monthly sales performance in 2023
4. Top products by revenue
5. Average customer spend
6. Sales performance of the top 5 products
7. Top 10 cities by number of orders
8. Order quantity vs. delivery time
9. Revenue comparison across occasions
10. Product popularity by occasion

## Tools
Microsoft Excel (Power Query, Pivot Tables, Pivot Charts, Slicers, Timelines), MySQL (SQL joins)

## Dashboard results
| KPI | Value |
|---|---|
| Total orders | 1,000 |
| Total revenue | Rs. 35,20,984 |
| Average order value | Rs. 3,520.98 |
| Average delivery time | 5.53 days |

## Insights
- Anniversary and Raksha Bandhan were the highest-revenue occasions, while Diwali was the lowest.
- Colors was the top product category by revenue, well ahead of Soft Toys and Sweets.
- Revenue peaked in August and February; Imphal, Dhanbad and Kavali placed the most orders.
